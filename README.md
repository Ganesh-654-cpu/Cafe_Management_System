# Cafe Management System

A simple Python-based Cafe Management System that allows users to place food orders and calculate the total bill.

## Features

* Display cafe menu with prices
* Order food items
* Add multiple items to the order
* Check item availability
* Calculate the total bill amount
* Simple command-line interface

## Technologies Used

* Python 3

## Menu

| Item   | Price (Rs) |
| ------ | ---------- |
| Pizza  | 50         |
| Pasta  | 40         |
| Burger | 60         |
| Coffee | 80         |
| Salad  | 70         |

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Cafe_Management_System.git
```

2. Navigate to the project folder:

```bash
cd Cafe_Management_System
```

3. Run the Python file:

```bash
python hotelmenu.py
```

or

```bash
py hotelmenu.py
```
